Your work.
The short version.

Run locally with Python 3.10+. No API key or upload. The CLI finds the session for this directory and writes a video.

Run without installing
uvx sessionreel

Newest session in this directory → reel.mp4

Choose a session.

Use the current session, an ID prefix, or a JSONL file. The bundled demo needs no personal logs.

sessionreel
sessionreel 5e55a0d0
sessionreel /path/to/session.jsonl
sessionreel list
sessionreel demo

A long session is scoped to one episode. Use --whole to include the full session.

Install your way.

Install with pipx, or run the latest repository version with uvx.

pipx install sessionreel
uvx --from git+https://github.com/mandu5/sessionreel sessionreel

Uses ffmpeg on your PATH, or the static build supplied by imageio-ffmpeg. Fonts are bundled.

Make the cut.
Keep the evidence.

Review the storyboard before rendering. Change captions, drop a scene, or adjust its timing in JSON.

Plan, edit, render
sessionreel plan -o storyboard.json
$EDITOR storyboard.json
sessionreel render storyboard.json -o reel.mp4

The original fact stays alongside each caption for review.

Choose the frame.

Square 1080×1080 is the default. Export wide 1920×1080 or tall 1080×1920, add Korean captions, or create a GIF.

sessionreel --format wide
sessionreel --format tall
sessionreel --lang ko
sessionreel --gif

Keep it local.

Optional narration uses the OS voice. Add redaction patterns and replace the project name or hide the branch.

sessionreel --voice
sessionreel --redact 'ACME-\d+'
sessionreel --project "client app" --no-branch

Review before
you share.

Redaction runs on the parsed session before the storyboard exists, and again at render time over every storyboard string. It covers credential patterns, identities, and sensitive file contents. Captions whose numbers do not appear in scene data are flagged.

Redaction is pattern-based. Watch the video before you post it. SessionReel makes no network calls; nothing is uploaded by the CLI.
